Use the Mail Pilot API CLI when you want a thin wrapper around the public API for scripts, bots, or local automation.

The package is published to npm as `@mailpilot/api`, and the executable name is `mail-pilot-api`.

## Run with npx

Requires Node.js `18+`.

```bash
npx @mailpilot/api --help
```

You can also install it globally:

```bash
npm install -g @mailpilot/api
```

## Configure access

The CLI reads configuration in this order:

1. Command flags
2. Environment variables
3. `~/.mail-pilot-api/config.json`

Supported environment variables:

- `MAIL_PILOT_API_KEY`
- `MAIL_PILOT_BASE_URL` for self-hosted or custom API deployments

Example:

```bash
mail-pilot-api rules list
```

`base-url` is optional. The CLI defaults to `https://www.mailpilot.app` and only needs an override for self-hosted or custom deployments.

Set `MAIL_PILOT_API_KEY` in your shell or secret manager before running commands. Avoid passing API keys as CLI arguments because they can leak into shell history and process listings.

## Common commands

List rules:

```bash
mail-pilot-api rules list
mail-pilot-api rules list --json
```

Get a rule:

```bash
mail-pilot-api rules get rule_123 --json
```

Create a rule from JSON:

```bash
mail-pilot-api rules create --file rule.json
cat rule.json | mail-pilot-api rules create --file -
```

Update a rule from JSON:

```bash
cat rule.json | mail-pilot-api rules update rule_123 --file -
```

Delete a rule:

```bash
mail-pilot-api rules delete rule_123
```

Read stats:

```bash
mail-pilot-api stats by-period --period week --json
mail-pilot-api stats response-time --json
```

Unsubscribe from a sender:

```bash
mail-pilot-api senders unsubscribe news@example.com
mail-pilot-api senders unsubscribe news@example.com --json
```

Fetch the live OpenAPI document:

```bash
mail-pilot-api openapi --json
```

For bots, prefer `--json` so the output is stable and machine-readable.
